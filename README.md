# 应对约束论

注意力预算下的响应、恢复与竞争。2026-10-20 定稿。

> 本库为「**注意力预算**（Attention Budget）」系列之一。系列不设族序号——体系开放，日后可续增；族以字母代号与书名相区别。

## 一 本件讲什么

扰动、威胁与竞争之下，如何在刚性预算内响应与恢复。B1 承共享正式版（只作数值域化），B2 域化·结构面，B3 域化·容量面。

一句话：**恢复独立于响应，应急过度必致恢复不足**。

## 四 次生原语

原语只有一对——不确定性（熵 `H`）／确定性（互信息 `I`）。约束不是原语，是原语对的**第一派生**，由「赋价」（转换必付代价）与「共享」（多主体须经共享结构）合成；「层级」属前提，不入合成式。

次序四步：**原语对 ⇒ 次生原语（约束）⇒ 概念体系 ⇒ 字典**。

七族是**同一条约束在七个机制面上的展开**——截断／格式／取舍／分配／存调／配平／反应。故各族体例同一、命题格式同一、证伪条件同一，可以并读；而各族凡例皆声明「自成一卷，不引用其他著作」，故也可单读。

## 五 「论」是文体

此「论」取《文心雕龙·论说》之义，是一种**文体**，不是「理论」的省称。

故《应对约束论》读作「关于应对的论」，不读作「应对的理论」。书中命题逐条附证伪条件与成立程度，凡未标定者明标未标定，凡不能设想出反例者不入卷——这是文体之内的自律，不是理论之名的担保。
